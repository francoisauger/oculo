Vos vidéos, sur le grand écran.

Oculo est une app libre pour Android TV et Google TV. Elle lit YouTube dans une interface calme, faite pour la télécommande et lisible du divan.

Voir le code sur GitHub Installation : à la sortie de la version 1.0.

←↑↓→ Cette télé fonctionne : cliquez dessus, puis essayez les flèches du clavier.

Reprendre où vous étiez

La rangée « Continuer à regarder » garde les vidéos commencées depuis 48 heures. Elle se remplit à partir de ce qui est sur la télé, sans aucun appel réseau.

Un appui long sur une vidéo, et elle n’y revient plus.

La lumière suit l’image

Le fond prend la couleur de la vignette sélectionnée et l’anneau blanc respire doucement. On sait toujours où on est, même du fond du salon.

Les commandites passent toutes seules

SponsorBlock saute les segments signalés par sa communauté. Un avis discret le dit, puis s’efface.

Rien ne sort de la télé sans raison

Aucun pistage, aucun rapport de plantage. Même le code QR de connexion est fabriqué sur la télé, sans passer par un service tiers.

D’où vient Oculo

Oculo est basé sur SmartTube de yuliskov (licence MIT). Le moteur de lecture est le sien, intact. Oculo en change l’interface.

Tout le code est public : le dépôt, la licence, la liste de ce qui a été changé.

Oculo n’est pas affilié à YouTube ni à Google. Ce site ne charge rien d’ailleurs : ni pisteur, ni police externe. Oculo, by Arix
